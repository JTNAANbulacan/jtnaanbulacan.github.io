Installation guide

Choose your device

Windows

Open the JTNAAN Hub in Chrome or Edge. Select the install icon in the address bar, or open the browser menu and choose Install JTNAAN Worship Team Hub if offered.

macOS

Open the JTNAAN Hub in a supported version of Chrome or Edge and use the install option in the address bar or browser menu. Safari users can add a website shortcut from the Share menu where supported.

Android

Open the JTNAAN Hub in Chrome. Tap the three-dot menu and choose Install app or Add to Home screen, then follow the prompts.

iPhone / iPad

Open the JTNAAN Hub in Safari. Tap Share, scroll the sheet and choose Add to Home Screen, then tap Add.

Installation creates an app-like shortcut. Full offline use and laptop-hosted local sessions are being added in staged releases; do not assume the current installed version can yet run every feature without internet.

Tutorials · no login required

Learn JTNAAN step by step

1. Install JTNAAN on your device
Open JTNAAN Hub in your device's supported browser, then follow the matching Windows, macOS, Android or iPhone/iPad steps above. If the browser does not show an install option, use its Add to Home Screen or Create Shortcut option.
2. Understand Offline Mode
Offline support is being introduced in phases. The current web app still relies on its online account and cloud services for shared data and live synchronization. Wait for the offline-ready release notice before relying on it during a service without internet.
3. Join a Worship Session
Open the app, sign in with your existing authorized account, then select the available Presenter or Worship Hub workspace. Local Wi-Fi/hotspot joining with a session QR code or code will be enabled in a future local-session release.
4. Understand automatic updates and patch numbers
The planned release numbering starts at Application Patch 1.0, followed by 1.1, 1.2 and so on. Content updates such as new songs and media will use a separate Content Patch number. The automatic update service is not active yet; updates will be announced when published.
5. Use Presenter
From the app dashboard, open Live Session and choose Presenter if your account has permission. Prepare song slides, Scripture, backgrounds and presentation controls. Use the workspace's Home control to return to the dashboard.
6. Use Worship Team Hub
From Live Session, choose Worship Hub if your account has permission. Use the song library, setlist, lyrics, chords, vocalist and instrumentalist views, monitors and tuner available to your role.
