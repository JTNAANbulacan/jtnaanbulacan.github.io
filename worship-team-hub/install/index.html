Quick installation guide

Windows laptop / desktop
Open this page in Chrome or Edge. Select the install icon in the address bar, or open the browser menu and choose Install JTNAAN Worship Team Hub / Install page as app. Confirm Install.
Mac
In Chrome or Edge, open the browser menu and choose the install option if shown. In supported Safari versions, open the JTNAAN page and choose File → Add to Dock.
Android phone / tablet
Open this page in Chrome. Tap the three-dot menu, choose Install app or Add to Home screen, then confirm.
iPhone / iPad
Open this page in Safari. Tap the Share button, scroll down and select Add to Home Screen, then tap Add. Other iOS browsers may not offer this option.
Tutorials · no login required

Learn JTNAAN step by step

1. Install JTNAAN on your device
Choose your device above. If your browser supports direct installation, use its prompt. Otherwise follow the short guide for your device.
2. Understand Offline Mode
The current web app still relies on its online account and cloud services for shared data and live synchronization. Do not rely on it to run a complete worship service without internet.
3. Join a Worship Session
Open the app, sign in with your existing authorized account, then select the available Presenter or Worship Hub workspace.
4. Understand updates
JTNAAN is served from the official website. Published web-app changes are delivered when the app reconnects and reloads; no separate installer download is required for ordinary website updates.
5. Use Presenter
From the app dashboard, open Live Session and choose Presenter if your account has permission. Prepare song slides, Scripture, backgrounds and presentation controls. Use the workspace's Home control to return to the dashboard.
6. Use Worship Team Hub
From Live Session, choose Worship Hub if your account has permission. Use the song library, setlist, lyrics, chords, vocalist and instrumentalist views, monitors and tuner available to your role.
